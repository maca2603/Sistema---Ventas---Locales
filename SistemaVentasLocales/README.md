# Sistema de Ventas Locales

Sistema de gestión de ventas desarrollado en **C# con Windows Forms**.

## Funcionalidades

- Gestión de productos y stock.
- Registro y control de ventas.
- Historial de ventas y tickets.
- Registro de movimientos de stock.
- Administración de usuarios.
- Configuración del negocio.
- Modo oscuro y ajuste del tamaño de fuente.
- Impresión y guardado de tickets.

## Tecnologías utilizadas

- C#
- .NET
- Windows Forms
- Visual Studio
- Archivos JSON para almacenamiento de datos.

## Proyecto

Aplicación de escritorio orientada a facilitar la administración de ventas y el control de stock de un comercio.
